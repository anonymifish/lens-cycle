验证：已安装的 0.1.0 通过正式 Tauri IPC 创建测试记录；0.1.1 Release EXE 打开同一数据库

schema 版本 1 和偏好均可反读。

`0.1.0 → 0.1.1` 覆盖安装成功，注册表、文件版本和安装日志均为 0.1.1/退出码 0。MSI
安装版读取旧版隔离数据库成功，写入新记录后强制关闭并重启，三条跨版本记录均可反读；
MSI 卸载后隔离数据库仍存在。

重新安装 MSI 0.1.1 作为本机最终状态。Tauri 的跨安装器路径记忆会使从 NSIS 切回 MSI 时
沿用 `%LOCALAPPDATA%\Lens Cycle`；最终状态是 Windows Installer 注册的 0.1.1，启动和反读
通过。该路径变化不涉及默认 Tauri 应用数据目录。六项缺陷的真实界面人工操作和完整 169
