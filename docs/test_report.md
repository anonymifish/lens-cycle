### 安装版桌面闭环补充验收

后续改用项目自带的 WebView2 CDP 桌面驱动连接 Program Files 中的 0.1.2 安装版，并把
`LENS_CYCLE_DATA_DIR` 定向到
`data/installed-msi-ui-acceptance`。在真实 Tauri 界面中创建“验收品牌 · 四位小数测试”
产品，录入 2 片、平均每片 `12.3456` 元。库存页固定显示 `¥12.3456 / 片`，库存价值和
统计页购买支出均按人民币规则显示为 `¥24.69`；SQLite 只读核对值为整数 `123456`，
`quick_check=ok`、外键错误为 0、迁移为 `[1, 2]`。编辑表单能够反显 `12.3456`，改为
`12.3400` 后界面固定显示四位小数、总值为 `¥24.68`，再改回 `12.3456` 成功。

点击设置页“退出应用”后，Lens Cycle 进程退出，主库由 4 KB/WAL 状态完整落盘为 192512
字节，WAL 和 SHM 均由 SQLite 移除。使用同一隔离目录再次启动后，界面仍显示
`¥12.3456 / 片` 和 `¥24.69`。随后通过已注册的 Tauri `close-requested` 前端回调执行窗口
关闭处理，进程退出后同样只剩主数据库文件；这覆盖了窗口关闭事件处理链，但不等同于用
系统级指针实际点击标题栏关闭按钮。

数据位置迁移使用安装版 Rust 命令把数据库迁移到
`data/installed-msi-ui-relocated`，并执行正式 `restart_app`。重启后设置页显示新的自定义
目录，产品、数量、四位价格和总值均保持不变；旧目录数据库保留且无活动侧车文件。为覆盖
异常恢复，在迁移后的进程上执行一次明确的强制结束，再从原隔离根目录启动；应用按位置
配置重新打开目标库，界面数据完整。最后从设置页安全退出，新旧两份数据库均
`quick_check=ok`、外键错误为 0、价格为整数 `123456`、迁移为 `[1, 2]`，两个目录都只剩
主数据库文件。用户 `%TEMP%` 与 `C:\Windows\Temp` 未发现 Lens Cycle 专用测试残留。

随后在迁移后的目标库上保留一个外部 WAL 读事务，并通过界面把单位价格提交为
`12.3455`，使正常退出时的 `wal_checkpoint(TRUNCATE)` 无法取得独占机会。应用按预期保持
打开，WAL 保留为 12392 字节，界面明确显示“无法安全退出”和“SQLite WAL checkpoint
未能取得独占写入机会”。释放读事务后再次点击退出成功，进程结束且 WAL/SHM 由 SQLite
移除；目标库最终 `quick_check=ok`、外键错误为 0，价格为整数 `123455`。这项真实安装版
测试覆盖了 checkpoint 失败阻止退出、错误提示和可重试恢复路径。

本次补充验收未逐项执行系统级指针点击标题栏关闭按钮、安装版 JSON 备份/文件选择恢复、
MSI 卸载重装、NSIS 安装卸载以及完整 169 项人工清单。发布负责人于 2026-09-13 明确接受
现有自动化、Release、覆盖安装和隔离桌面证据作为替代，并确认 0.1.2 可以发布；这些未
