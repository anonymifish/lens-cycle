## 1. 本次升级目标

本次升级包含两项相互独立、但都必须通过“写入后完全退出并重启反读”验证的数据完整性
改进：

1. 建立统一的正常退出与重启收尾流程：先完成待提交保存，再执行
   `PRAGMA wal_checkpoint(TRUNCATE)`，显式关闭 SQLite 连接，确认成功后才允许应用退出或
   重启。
2. 将库存批次的平均每单位价格统一升级为万分之一元定点整数，支持输入、保存、编辑、
   备份恢复和重启后显示最多 4 位小数，并保证统计总金额按人民币金额规则舍入和显示。

这两项升级不得引入浏览器存储或内存业务数据回退，不得直接删除 SQLite 的 `-wal`、
`-shm` 文件，也不得改写已经发布的初始迁移。

## 2. 实施前差距与确定口径

### 2.1 正常退出与 SQLite 连接生命周期

实施前，窗口关闭流程只在前端等待偏好设置 flush，随后调用 Rust `exit_app`；Rust 的
`exit_app` 和 `restart_app` 直接请求 Tauri 退出或重启。数据库已有
`wal_checkpoint(TRUNCATE)` 能力，但尚未形成覆盖所有退出入口的“保存屏障、checkpoint、
显式关闭、确认退出”统一流程。

本次升级采用以下固定顺序：

1. 进入关闭状态，阻止新的业务写入和重复退出请求；
2. 等待已经开始的业务写入完成，并 flush 所有待保存设置；
3. 执行 `PRAGMA wal_checkpoint(TRUNCATE)` 并检查返回结果；
4. 从应用数据库状态中取出并显式关闭 SQLite 连接；
5. 只有前述步骤全部成功后，才执行最终退出或重启。

保存、checkpoint 或关闭任一步骤失败时，应用保持打开并恢复到可重试状态，向用户显示
包含失败阶段的明确错误。不得出现窗口已经消失、数据库却没有完成正常收尾的状态。

正常关闭后，已提交 WAL 内容必须合并回主数据库；`-wal` 应被截断为零或由 SQLite 自动
移除，`-shm` 由 SQLite 在最后一个连接关闭后自行清理。即使平台暂时保留 `-shm`，其中
也不得存在未完成的数据状态。程序不以文件删除代替 checkpoint 或连接关闭。

任务管理器强制结束、进程崩溃和系统断电属于异常退出，不承诺当场移除侧车文件；下次
启动必须按 SQLite WAL 语义安全恢复已提交数据，再完成健康检查和正常加载。

### 2.2 平均单位价格的定点口径

已发布的初始 schema 将 `stock_lots.unit_price_minor` 声明为 `REAL`，Rust 模型却按 `i64`
读写；前端换算仍可能产生带小数的“分”，因此第 3、4 位小数不能在整个链路中可靠保持。

升级后的统一口径为：

- 平均每单位价格使用整数保存，比例固定为 `1 元 = 10000`；
- 输入最多接受 4 位小数，单位价格固定显示 4 位小数，例如 `12.3456 元`；
- 前端领域模型、IPC、Rust、SQLite、备份与恢复均传递同一个定点整数，不用二进制浮点数
  保存或跨边界传递金额事实；
- 库存价值、购买支出等总金额使用定点整数完成中间计算，只在最终人民币金额展示处统一
  舍入；实施时必须在现行需求和测试中明确舍入模式及正好位于舍入边界的行为；
- 通过新增顺序迁移升级现有数据库，不修改 `001_initial.sql`；现有两位小数价格按比例精确
  转换，例如旧口径的 1234 分转换为 123400 个万分之一元，仍表示 `12.3400 元`；
- 迁移必须在事务中完成，校验非负、整数和范围约束，失败保留原数据库；
- 旧版本已经截断或丢失的第 3、4 位不猜测、不伪造，升级后允许用户通过正常批次编辑
  手动更正。

备份格式需要显式标识价格比例或提升格式版本。恢复必须兼容旧的两位小数备份，并在写入
新数据库前完成确定性的比例转换和完整性校验；新格式备份恢复后不得损失 4 位精度。

## 5. 发布验收标准

以下条件必须全部满足，才能将本次升级标记为可发布：

- 写入一条新数据后正常关闭，主数据库包含最新提交。
- 关闭后不存在仍持有数据库文件的 Lens Cycle/WebView2 进程。
- WAL 已截断或移除，SHM 状态符合 SQLite 正常关闭行为。
- 连续启动和关闭多次，数据保持一致。
- 模拟保存或 checkpoint 失败时，应用不直接退出并显示明确错误。
- 强制结束应用后重新启动，数据能够从 WAL 恢复。
- 数据位置迁移并重启后，旧、新目录数据完整且没有活动 WAL 遗留。
- 覆盖安装和卸载重装测试中，用户数据保持不变。
- C 盘常见临时目录中不存在构建或安装测试残留。
- `12.3456 元` 能够新增、保存、编辑、备份恢复并在完全退出重启后原样显示。
- 旧两位小数价格升级后数值不变，统计总金额计算和人民币展示舍入正确。
