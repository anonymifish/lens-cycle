# Lens Cycle 0.1.4 发布记录

> 状态：0.1.4 Windows 发布包已构建。本文记录本次功能修复、自动验证和发布产物，不替代现行
> 需求、设计、测试文档或 169 项验收清单。

## 1. 发布内容

0.1.4 包含三项时间轴与产品联动改进，不改变 SQLite schema，也不新增依赖：

1. 已经恢复或结束的历史暂停片段可以删除；删除后相邻使用阶段自动合并，当前暂停仍需先
   恢复使用。
2. 修改开封瓶产品的开封后有效期时，关联实例的开封失效日和最终预测日同步更新。
3. 同一用品配置内按产品顺序分配连续轨道，同一产品实例上下相邻，产品内按启用日期分配
   重叠轨道。

## 2. 实现与数据语义

- 删除历史暂停只修改生命周期状态区间，不删除使用事实或库存流水；开封瓶和批量耗材会
  同步扣除被删除暂停对耗尽预测造成的顺延。
- 产品有效期与关联时间轴实例通过同一个 SQLite 增量事务提交，失败时产品和时间轴均不
  发布候选状态。
- 开封瓶最终预测日继续取预计耗尽日与开封失效日中的较早者。
- 时间轴产品分组遵循产品 `sortOrder`，每个产品占用连续轨道；移出当前视窗的实例不保留
  空轨道。
- 版本继续使用 schema generation `current-2` 与迁移 `[1, 2]`，0.1.3 数据库无需迁移。

可直接从 0.1.3 覆盖安装 0.1.4。覆盖安装不应删除或替换用户数据库与 JSON 备份；升级前
仍建议从设置页创建一次 JSON 备份。安装包未进行 Authenticode 签名，Windows 可能显示
未知发布者或 SmartScreen 提示。
