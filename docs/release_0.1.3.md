# Lens Cycle 0.1.3 缺陷修复发布记录

> 状态：0.1.3 Windows 发布包已构建。本文记录本次修复、自动验证和发布产物，不替代现行需求、设计、
> 测试文档或 169 项验收清单。

## 1. 发布内容

0.1.3 包含三项缺陷修复，不改变 SQLite schema，也不新增依赖：

1. 修复删除已有护理液等误录使用实例时，SQLite 将历史反向流水误判为仍然有效的实例关联，
   从而报错“有效库存流水关联的使用实例不存在”的问题。
2. 修复日期输入组件右侧日历按钮被透明原生日期控件覆盖，点击按钮没有反应的问题。
3. 修复多天使用软镜转移地点后，“启用下一片”流水遗漏当前地点并错误回退到批次入库地点，
   从而触发原地点库存为负数的问题。

## 2. 实现与数据语义

- 删除误录实例时反向该实例当前仍有效且允许随实例撤销的全部库存影响，不修改或删除任何
  已提交流水。
- 历史反向流水和明确标记为不随实例撤销的开盒记录可继续保留审计关系，不再被误判为有效
  孤儿流水。
- 使用事实、护理事件、实例删除及新增反向流水仍在同一个 SQLite 事务中提交；失败时 Store
  和界面不发布候选状态。
- 日期文本框与可见日历按钮都调用同一个原生日期选择器；透明辅助控件不再截获指针事件。
- 多天使用软镜启用、编辑或删除盒内镜片时，库存流水使用业务日期对应的实例地点历史；地点
  转移后的剩余库存从新地点扣减或恢复。
- 版本继续使用 schema generation `current-2` 与迁移 `[1, 2]`，0.1.2 数据库无需迁移。
