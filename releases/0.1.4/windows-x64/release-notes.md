# Lens Cycle 0.1.4 Windows x64

## 更新内容

- 支持删除已经恢复或结束的历史暂停片段，并自动合并相邻使用阶段；当前暂停仍需先恢复。
- 修改开封瓶产品的开封后有效期时，在同一 SQLite 事务中同步关联时间轴实例的开封失效日
  和最终预测日，失败时产品与时间轴一起回滚。
- 同一用品配置内按产品顺序分配连续轨道，同一产品实例上下相邻，产品内再按启用日期分配
  重叠轨道。

## 数据兼容性

- 本版本不改变 SQLite schema，不新增迁移或依赖，继续使用 schema generation
  `current-2` 和迁移 `[1, 2]`。
- 可从 0.1.3 覆盖安装并继续使用原数据库。升级前仍建议从设置页创建 JSON 备份。
