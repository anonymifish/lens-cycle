# Lens Cycle 0.1.1 Windows x64

## 修正内容

- 修正误录使用实例删除时页面卡住，并在 SQLite 提交后恢复对应库存。
- 修正暂停、恢复、结束和撤销结束经过整快照写入造成的页面卡顿。
- 所有管理模板统一显示生命周期历史，并允许编辑已有暂停区间。
- 时间轴活动实例移动地点时，同步转移来源批次在原地点的全部剩余库存；库存页仍由用户
  指定转移数量。
- 批量消耗品结束时要求填写实际剩余数量，通过损耗或盘盈更正流水保持账实一致。
- 区分“预计剩余”和“实际库存”，并修正当天结束后时间条看起来增加一天的问题。

## 数据兼容性

- 本版本未改变 SQLite schema，保持应用标识 `com.lenscycle.desktop`，支持从 0.1.0 覆盖
  安装并继续使用原数据。
- 2026-09-09 已验证 0.1.1 Release EXE 可读取由 0.1.0 在隔离目录创建的数据库，旧版记录
  保留；新版写入后强制关闭并重启，旧版和新版记录均可反读。
- 2026-09-10 已完成 MSI `0.1.0 → 0.1.1` 覆盖安装、启动、写入、强制关闭反读和卸载
  数据保留验证；也完成 NSIS 安装、启动、旧数据反读和卸载数据保留验证。
- 在 MSI 与 NSIS 安装器类型之间切换时，Tauri 会沿用上一次安装目录；这不改变 Tauri
  应用数据目录，也不影响 SQLite 数据。
