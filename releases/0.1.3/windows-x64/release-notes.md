# Lens Cycle 0.1.3 Windows x64

## 修正内容

- 修复已有护理液等使用实例在保留历史反向流水时，删除误录记录失败并提示“有效库存流水
  关联的使用实例不存在”的问题。
- 删除误录实例时撤销全部当前有效且允许撤销的库存影响；原流水保持不可变，只追加反向
  流水。
- 修复日期输入框右侧日历按钮被透明原生控件遮挡、点击无响应的问题；点击日期文本框或
  日历按钮现在均可打开日期选择器。
- 修复多天使用软镜转移地点后，启用下一片错误地从原入库地点扣减、导致原地点库存为负数
  的问题；启用、编辑和删除镜片现在按业务日期对应的地点历史记账。

## 数据兼容性

- 本版本不改变 SQLite schema，不新增迁移或依赖，继续使用 schema generation
  `current-2` 和迁移 `[1, 2]`。
- 可从 0.1.2 覆盖安装并继续使用原数据库。升级前仍建议从设置页创建 JSON 备份。
